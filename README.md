# 🏍️ Bajaj Showroom Stock & Billing Management App

A real-world web application built to solve stock leakage, billing mistakes, and spare-parts tracking problems in a Bajaj two-wheeler service showroom.

This is not a sample project. It was built for a real business and is actively used.

---

## 🎯 Why I Built This

My family runs a Bajaj service showroom.  
We were facing serious problems like spare parts going missing, manual billing errors, and no clear tracking of which vehicle used which part.

Instead of only complaining about the problem, I decided to solve it with code while learning web development in my first year of engineering.

---

## ⚙️ What This App Does

- Displays all spare parts with live stock count  
- Reduces stock only when a part is used  
- Stores exact date & time of each stock change  
- Links spare usage to vehicle number & customer name  
- Auto-generates bills with unique invoice numbers  
- Includes GST in final amount  
- Sends service messages via WhatsApp  
- Separate Owner & Staff login system  
- Low-stock alert panel  
- Saves all bills locally for future reference  
- Printable invoice format

## 🧭 How I Built This App – Stage by Stage

**Stage 1 – Problem Understanding**  
Identified how spare leakage and manual billing were harming the business.

**Stage 2 – Basic Stock Display**  
Created a list to show all spare parts with quantities.

**Stage 3 – Stock Reduction Logic**  
Implemented reduce-stock feature with time tracking.

**Stage 4 – Vehicle & Customer Linking**  
Every stock reduction now records vehicle number and customer name.

**Stage 5 – Billing System**  
Auto-numbered invoices with GST and printable format.

**Stage 6 – Role-Based Login**  
Owner and Staff login system with different controls.

**Stage 7 – WhatsApp Integration**  
Service & billing messages sent directly to customers.

**Stage 8 – Data Persistence**  
Used LocalStorage to keep data safe even after browser close.

**Stage 9 – UI Improvements**  
Clean layout for quick usage inside the showroom.

**Stage 10 – GitHub Protection**  
Learned Git & GitHub to protect the project from accidental loss.
